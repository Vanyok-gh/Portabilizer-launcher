# มีอะไรใหม่ใน Portabilizer

## v9.1

- ภาษาของอินเทอร์เฟซ: แท็บ "ภาษา" (พร้อมไอคอนลูกโลก) เหมือนในการตั้งค่า Windows: แต่ละภาษาแสดงด้วยชื่อของตัวเอง และด้านล่างเป็นชื่อในภาษาของอินเทอร์เฟซ แปลหน้าต่าง คำแนะนำ บันทึก กล่องโต้ตอบ และประวัติแล้ว เมื่อเปลี่ยนภาษา หน้าต่างจะรีสตาร์ต การตั้งค่าของคุณจะถูกเก็บไว้
- ภาษา: 34 (русский, English, Eesti, Français, Español, Deutsch, Italiano, Português, Nederlands, Polski, Українська, Svenska, Suomi, Türkçe, 中文, 日本語, 한국어, العربية, Čeština, Română, Magyar, Ελληνικά, עברית, हिन्दी, Indonesia, Tiếng Việt, ไทย, Български, Српски, Hrvatski, Latviešu, Lietuvių, Norsk, Dansk)
- เมื่อเปิดครั้งแรกจะใช้ภาษาของ Windows (หากมีอยู่ในภาษาที่แปลแล้ว) หากไม่มีจะใช้ภาษาอังกฤษ
- ไฟล์ portabilizer.log ยังคงเขียนเป็นภาษารัสเซีย ซึ่งช่วยให้หาสาเหตุของข้อผิดพลาดได้ง่ายขึ้น

## v9.0

- ไม่ต้องติดตั้งไลบรารี: โปรแกรมจะดูว่าเกมหรือแอปต้องใช้ไลบรารีใด แล้วเสนอให้วางไว้ข้างๆ exe (ไฟล์ฝังอยู่ใน Portabilizer)
- DirectX: รุ่นมิถุนายน 2010 และรุ่นเก่า 2005-2009 (d3dx9_24…43, d3dx10, XACT, XAudio, xinput) สำหรับเกมเก่า
- Visual C++ 2010, 2012, 2013 และ 2015-2022, OpenAL (พร้อม wrap_oal.dll)
- ชุด cab ที่โปรแกรมอ่านเองไม่ได้จะไม่ถูกข้ามอีกต่อไป: expand.exe (Windows) จะเป็นผู้แตกไฟล์
- ชุดไลบรารีสร้างด้วยสคริปต์ tools/collect_redist.bat

## v8.9

- โหมด R: exe ปกติจะไม่ถูกคัดลอกอีกต่อไป แต่จะถูกย้ายไปยังโฟลเดอร์ App ในไดรฟ์เดียวกันจะเสร็จทันทีและไม่ต้องใช้พื้นที่เพิ่ม (ก่อนหน้านี้ต้องใช้พื้นที่สองเท่าระหว่างทำงาน)
- สำหรับไฟล์เก็บถาวรและตัวติดตั้ง โหมด R ยังต้องใช้พื้นที่: จะแตกไฟล์ก่อน แล้วจึงลบต้นฉบับ คุณสามารถแตกไฟล์ไปยังไดรฟ์อื่นได้ผ่านช่อง "ปลายทาง"
- อัปเดตคำแนะนำและหน้าต่างยืนยันของโหมด R แล้ว
- ไอคอนปากกาแบบพิกเซล (สีน้ำเงินสำหรับเวอร์ชันปกติ สีแดงสำหรับ R) พร้อมธีม "คลาสสิก (ระบบ)" ธีมอื่นใช้ไอคอนแบบเรียบเนียนเหมือนเดิม

## v8.8

- ตรวจสอบการอัปเดต: โปรแกรมตรวจสอบ GitHub Releases เอง และแจ้งเมื่อมีเวอร์ชันใหม่ (ปิดได้ด้วยช่องทำเครื่องหมายในแท็บ "เวอร์ชัน")
- ทำงานร่วมกับ Portabilizer Launcher ได้ดีขึ้น: เวอร์ชันเป็นรายการ คำอธิบาย "มีอะไรใหม่" ติดตั้งในคลิกเดียว

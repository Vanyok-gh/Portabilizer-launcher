# Что нового в Portabilizer

Лаунчер показывает этот текст на вкладке «Что нового», если у релиза на GitHub нет своего описания.
Заголовок каждой версии: `## v8.9`.

## v8.9

- Режим R: обычный exe больше не копируется, а переносится в папку App. На одном диске это мгновенно и без дополнительного места (раньше на время работы нужно было вдвое больше)
- Для архивов и установщиков в режиме R место всё ещё нужно: сначала они распаковываются, и только потом исходник удаляется. Распаковать можно на другой диск через поле «Куда»
- Обновлены подсказка и окно подтверждения режима R
- Пиксельные иконки пера (синее у обычной версии, красное у R) при теме «Классическая (системная)»; в остальных темах иконки гладкие

## v8.8

- Проверка обновлений: программа сама сверяется с GitHub Releases и сообщает, что вышла новая версия (отключается галочкой во вкладке «Версии»)
- Лучше работает вместе с Portabilizer Launcher: версии списком, описание «что нового», установка одним нажатием

## v8.7

- Темы оформления: светлая, тёмная, красные темы для режима R, выбор своего цвета
- Автоматический поиск установленного 7-Zip
- Библиотеки DirectX внутри программы (диалог, если игре их не хватает)
- Запуск без запроса UAC для программ, которые просят права администратора
- Убран дубль подсказки про память

# Portabilizer Launcher

**Менеджер версий для [Portabilizer](https://github.com/Vanyok-gh/Portabilizer): одной кнопкой скачивает нужную версию, проверяет её и запускает в обычном режиме или в режиме R.**

*English: Portabilizer Launcher lists the releases of Portabilizer, installs any of them with one click (checksum verified), starts it in normal or radical (R) mode and can put a shortcut on the desktop. 34 interface languages.*

## Для чего это нужно

**Portabilizer** превращает установщик или архив в портативную папку (программа или игра, которая запускается без установки
в систему). Подробнее о нём в [его описании](https://github.com/Vanyok-gh/Portabilizer).

У Portabilizer много версий, и скачивать их вручную неудобно: надо искать нужный релиз на GitHub, качать файл,
распаковывать, помнить, где что лежит. Лаунчер делает это за вас:

- показывает все версии списком, новые сверху, пробные помечены `[Beta]`;
- ставит выбранную версию одной кнопкой: скачивает, **проверяет контрольную сумму** и раскладывает по своей папке;
- каждая версия лежит отдельно и не мешает другим: можно держать новую и старую рядом;
- запускает версию обычным способом или в режиме **R** (радикальный: после сборки удаляет исходный установщик или архив);
- сообщает, когда вышла новая версия Portabilizer или сам лаунчер;
- показывает, **что нового** в каждой версии;
- создаёт ярлык на рабочем столе для лаунчера и для любой установленной версии;
- работает на 34 языках.

Без интернета лаунчер показывает последний сохранённый список и уже установленные версии.

## Установка (пошагово, Windows)

Лаунчер ставить не нужно: это один файл, который запускается двойным щелчком.

1. Откройте страницу релизов лаунчера: **[github.com/Vanyok-gh/Portabilizer-launcher/releases](https://github.com/Vanyok-gh/Portabilizer-launcher/releases)**.
2. В самом верхнем релизе (помечен зелёным **Latest**) найдите раздел **Assets** и скачайте файл
   **`Portabilizer.Launcher.exe`**. (Файл `Portabilizer-Launcher-vX.Y.zip` содержит тот же exe в архиве.)
3. Создайте для лаунчера отдельную постоянную папку, например `D:\Portabilizer` или `C:\Tools\Portabilizer`.
   Не запускайте его прямо из «Загрузок» и не из архива: рядом с exe лаунчер хранит свои настройки и скачанные версии
   (папка `versions`).
4. Переместите `Portabilizer.Launcher.exe` в эту папку и запустите его двойным щелчком.
5. Windows может показать синее окно SmartScreen «Windows защитила ваш компьютер». Это бывает с любой новой программой
   без платной подписи. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
6. При первом запуске лаунчер предложит создать ярлык на рабочем столе. Согласитесь, так его проще открывать.
7. Подождите несколько секунд: лаунчер загрузит список версий с GitHub. Нужен интернет.

## Как пользоваться

**Установить и запустить Portabilizer**

1. В списке слева выберите версию (обычно самую верхнюю).
2. Нажмите большую кнопку **«Установить»**. Появится полоса загрузки; при необходимости загрузку можно отменить.
3. Когда версия установится, кнопка сменится на **«Запустить»**. Нажмите её: откроется Portabilizer.
4. Внизу слева переключатель режима: **«Обычный режим»** или **«Режим R»**. R удаляет исходный файл после успешной
   сборки, Portabilizer перед этим всегда просит подтверждение.

**Ярлык версии на рабочем столе.** После установки лаунчер спрашивает, создать ли ярлык этой версии. Ярлык запускает
Portabilizer напрямую, без лаунчера (в режиме R с ключом `--r`). Вопрос можно отключить в «Лаунчер» -> «Предлагать ярлык
после установки». Создать ярлык позже: кнопка **≡** -> «Создать ярлык выбранной версии на рабочем столе».

**Язык.** Вкладка с глобусом справа. Название языка написано сверху на нём самом, под ним на языке, который сейчас выбран
(как в настройках Windows). После выбора окно само перезапустится. При первом запуске берётся язык Windows.

**Что нового.** Вкладка «Что нового» показывает описание выбранной версии.

**Другие кнопки.** «Инфо» - подробности о версии, «Папка» - открыть папку версии, «Обновить» - перечитать список с GitHub,
**≡** - меню (настройки, менеджер версий, добавить свою версию, удалить версию, ярлыки).

**Вкладки справа**

| Вкладка | Что там |
|---|---|
| Что нового | Описание выбранной версии |
| Лаунчер | Папка для версий, показ пробных версий, закрытие после запуска, вопрос про ярлык |
| Менеджер версий | Установленные версии, размер, удаление, добавление своей версии (`.zip` или `.exe`) |
| Оформление | Светлая, тёмная, красные (для R) темы, свой цвет |
| Журнал | Что делал лаунчер |
| О программе | Версия лаунчера и ссылка на репозиторий |
| Язык | Выбор языка интерфейса |

## Что где лежит

Всё хранится рядом с `Portabilizer.Launcher.exe`:

| Что | Где |
|---|---|
| Установленные версии | `versions\<версия>\` (папку можно сменить во вкладке «Лаунчер») |
| Настройки | `launcher_settings.json` |
| Кэш списка версий | `releases_cache.json` |
| Свои темы | `themes\` |

Удалить лаунчер: закройте его и удалите папку целиком (вместе с версиями, если они вам не нужны). В систему лаунчер
ничего не устанавливает; единственное, что остаётся вне папки, это ярлыки на рабочем столе.

## Частые вопросы

**Список версий пустой или «Нет связи с GitHub».** Проверьте интернет и нажмите «Обновить». Без сети видны только
установленные версии и последний сохранённый список.

**У версии нет кнопки «Установить» («нет файла в релизе»).** В её релизе на GitHub нет собранной программы. Выберите
другую версию.

**Лаунчер пишет, что контрольная сумма не совпала.** Файл повреждён при загрузке или подменён. Установка отменена;
повторите её. Если повторяется, сообщите автору.

**Не открывается ярлык или его не удалось создать.** Ярлыки поддерживаются только в Windows. Попробуйте создать его
через меню **≡**.

**Как перенести лаунчер на другой компьютер.** Скопируйте папку целиком (exe, `versions`, настройки).

**Как обновить сам лаунчер.** При запуске он сообщит о новом выпуске и предложит открыть страницу загрузки. Скачайте
новый `Portabilizer.Launcher.exe` и замените им старый в той же папке: версии и настройки сохранятся.

## Для автора: как выпустить новую версию Portabilizer

Основной способ описан в [README Portabilizer](https://github.com/Vanyok-gh/Portabilizer#для-автора-как-выпустить-версию):
тег `vX.Y` -> GitHub сам собирает exe и создаёт релиз. Лаунчер подхватит его сам.

Вручную: приложите к релизу `Portabilizer.exe` или zip с ним (допустима одна вложенная папка), укажите тег вида `v9.0`.
Для пробной версии отметьте **Set as a pre-release** (в лаунчере будет `[Beta]`). GitHub сам считает SHA-256 файла, лаунчер его
проверяет; сумму можно также указать в описании строкой `SHA-256: <64 символа>` или приложить `SHA256SUMS.txt`.
Если суммы нет, лаунчер поставит версию без проверки и напишет об этом в журнале.

**Описание версии («Что нового»).** Лаунчер берёт описание релиза на GitHub. Если оно пустое или это только заголовок
вроде «Portabilizer v9.0», подставляется раздел `## v9.0` из `CHANGELOG.md` в `main` репозитория Portabilizer.

**Теги.** Версии Portabilizer: `v8.7`, `v9.0`, `v9.1-beta`. Всё, что не похоже на версию (например `launcher-v0.5` для самого
лаунчера), в список версий не попадает. Откуда лаунчер берёт версии, задаётся `VERSIONS_OWNER` / `VERSIONS_REPO` в `pz_core.py`
или настройкой `versions_repo` (`владелец/репозиторий`) в `launcher_settings.json`; по умолчанию `Vanyok-gh/Portabilizer`.

## Для разработчика

**Выпустить новую версию самого лаунчера.** Поднять `VERSION` в `launcher.py`, создать релиз с тегом `launcher-vX.Y`:
GitHub соберёт `Portabilizer Launcher.exe` на Windows и приложит его и zip к релизу
(`.github/workflows/release-launcher.yml`). Если релиз уже создан, workflow можно запустить вручную:
Actions -> Release launcher -> Run workflow, указав тег.

**Запуск и проверка.**

```
python launcher.py            # запуск из исходников (Python 3.9+ с tkinter)
build_launcher.bat            # сборка Portabilizer Launcher.exe в папку dist
python tests/test_core.py     # скачивание, суммы, безопасная распаковка
python tests/test_model.py    # список версий и окно (на поддельном tkinter)
python tests/test_updates.py  # уведомление о новой версии, фильтр тегов, ярлык
python tests/test_lang_shortcut.py   # смена языка и ярлык версии
python tests/test_i18n.py     # все ли тексты переведены
```

**Устройство**

| Файл | Что внутри |
|---|---|
| `launcher.py` | окно и модель (список версий, действия) |
| `pz_core.py` | GitHub Releases, скачивание, проверка суммы, установка, запуск, ярлыки |
| `pz_theme.py` | темы оформления и палитры с проверкой читаемости |
| `pz_i18n.py`, `pz_lang_data.py`, `lang/` | переводы интерфейса |
| `pz_icons.py`, `launcher.ico` | иконки (гладкие и пиксельные для темы «Классическая») |
| `tests/` | тесты без окна и без интернета |

**Переводы.** Русский текст в коде - ключ. Четыре языка (English, Eesti, Français, Español) лежат в `pz_i18n.py`
(`TABLE`), остальные 29 - в `lang/<код>.txt` (строки `номер<TAB>перевод`, номера из `lang/_source.txt`) и
`lang/<код>_names.txt` (названия языков на этом языке). После правки запустите `python tools/make_lang.py`: он пересоберёт
`pz_lang_data.py`. `python tools/check_lang.py lang/de.txt lang/de_names.txt` проверяет файл. Чтобы добавить язык: код в
`lang/_codes.txt`, два файла в `lang/`, перегенерация.

## Безопасность

- Распаковка не выходит за пределы папки версии (защита от `../` в архиве).
- Контрольная сумма проверяется до распаковки.
- Лаунчер только скачивает и запускает `Portabilizer.exe` из релизов репозитория-источника. Свой код из интернета он
  не исполняет.

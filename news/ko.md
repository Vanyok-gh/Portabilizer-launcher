# Portabilizer 새로운 기능

## v9.1

- 인터페이스 언어: Windows 설정과 같은 "언어" 탭(지구본 아이콘 포함). 각 언어는 자체 이름으로 표시되고 그 아래에 인터페이스 언어로 된 이름이 표시됩니다. 창, 힌트, 로그, 대화 상자, 기록이 번역되었습니다. 언어를 변경하면 창이 다시 시작되며 설정은 유지됩니다
- 언어: 34 (русский, English, Eesti, Français, Español, Deutsch, Italiano, Português, Nederlands, Polski, Українська, Svenska, Suomi, Türkçe, 中文, 日本語, 한국어, العربية, Čeština, Română, Magyar, Ελληνικά, עברית, हिन्दी, Indonesia, Tiếng Việt, ไทย, Български, Српски, Hrvatski, Latviešu, Lietuvių, Norsk, Dansk)
- 처음 실행할 때는 Windows 언어를 사용하고(번역된 언어에 포함된 경우), 그렇지 않으면 영어를 사용합니다
- portabilizer.log 파일은 여전히 러시아어로 기록되며, 덕분에 오류를 파악하기 쉽습니다

## v9.0

- 라이브러리를 설치할 필요가 없습니다. 프로그램이 게임이나 앱에 필요한 라이브러리를 파악해 exe 옆에 넣도록 제안합니다(파일은 Portabilizer에 내장되어 있습니다)
- DirectX: 오래된 게임용 2010년 6월 버전 및 2005-2009년 이전 릴리스(d3dx9_24…43, d3dx10, XACT, XAudio, xinput)
- Visual C++ 2010, 2012, 2013 및 2015-2022, OpenAL(wrap_oal.dll 포함)
- 프로그램이 직접 읽을 수 없는 Cab 세트도 더 이상 건너뛰지 않습니다. 압축 해제는 expand.exe(Windows)가 처리합니다
- 라이브러리 세트는 tools/collect_redist.bat 스크립트로 만들어집니다

## v8.9

- R 모드: 일반 exe는 더 이상 복사되지 않고 App 폴더로 이동됩니다. 같은 드라이브에서는 즉시 끝나며 추가 공간이 필요 없습니다(이전에는 작업 중에 두 배의 공간이 필요했습니다)
- 압축 파일과 설치 프로그램은 R 모드에서도 여전히 공간이 필요합니다. 먼저 압축을 푼 다음에야 원본이 삭제되기 때문입니다. "저장 위치" 필드를 사용해 다른 드라이브에 압축을 풀 수 있습니다
- R 모드 힌트와 확인 창을 업데이트했습니다
- "클래식(시스템)" 테마에서는 픽셀 연필 아이콘(일반 버전은 파란색, R은 빨간색)을 사용하고, 다른 테마에서는 부드러운 아이콘을 유지합니다

## v8.8

- 업데이트 확인: 프로그램이 직접 GitHub Releases를 확인하여 새 버전이 나오면 알려 줍니다("버전" 탭의 확인란으로 끌 수 있습니다)
- Portabilizer Launcher와 더 잘 연동됩니다: 목록으로 보는 버전, "새로운 기능" 설명, 클릭 한 번으로 설치

- 설치된 7-Zip 자동 검색
- 프로그램 내부의 DirectX 라이브러리(게임에 없으면 대화 상자가 나타납니다)

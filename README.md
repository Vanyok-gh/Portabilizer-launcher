# Portabilizer Launcher

Лаунчер версий **Portabilizer**: список версий слева, настройки справа. Любую версию можно
установить одной кнопкой и запустить в обычном режиме или в режиме **R** (радикальном).

Лаунчер скачивает версии из раздела **Releases** этого репозитория, проверяет контрольную сумму
файла и распаковывает каждую версию в свою папку `versions\<версия>\`. Версии не мешают друг другу.

## Что умеет (v0.4)

- Список версий из GitHub Releases (новые сверху, пробные помечены `[Beta]`). Без интернета
  показывается последний сохранённый список и уже установленные версии.
- Установка с полосой прогресса, отменой и проверкой SHA-256. Если сумма не совпала, установка
  отменяется.
- Запуск выбранной версии: обычный режим или R (в версию передаётся ключ `--r`).
- Кнопки: информация о версии (что нового), папка версии, обновить список, меню (настройки,
  менеджер версий, добавить свою версию, удалить версию).
- «Добавить свою версию»: старые версии (v5, v7.3 и т.п.) можно добавить из `.zip` или `.exe`.
- Вкладка «Что нового»: описание выбранной версии (берётся из описания релиза на GitHub).
- Уведомление о новой версии: при запуске лаунчер сам проверяет релизы, показывает синий баннер
  «Доступна новая версия» и один раз предлагает установить её.
- Ярлык на рабочем столе: при первом запуске собранного `Portabilizer Launcher.exe` лаунчер
  предлагает создать ярлык (потом: меню `≡` → «Создать ярлык на рабочем столе»).
- Язык интерфейса: вкладка с глобусом, русский, English, Eesti, Français, Español. При первом запуске
  exe берётся язык Windows. Смена языка перезапускает окно, настройки и версии сохраняются.
- Ярлык версии: после установки лаунчер спрашивает, поставить ли ярлык этой версии Portabilizer на рабочий
  стол (отключается в настройках; позже: меню `≡` → «Создать ярлык выбранной версии на рабочем столе»;
  в режиме R ярлык запускает версию с ключом `--r`).
- Оформление: светлая и тёмная темы, красные темы для режима R, выбор своего цвета, свои темы
  в папке `themes` (те же, что в Portabilizer).

## Как выпустить новую версию Portabilizer

1. Соберите `Portabilizer.exe` (`build.bat` из пакета Portabilizer).
2. Положите `Portabilizer.exe` в zip с именем вида `Portabilizer-v8.7.zip`. Внутри допускается
   одна вложенная папка (например, `dist`), главное, чтобы был файл `Portabilizer.exe`.
3. На GitHub: **Releases → Draft a new release**.
4. Тег: `v8.7` (формат `v<число>.<число>`, по тегам лаунчер сортирует версии).
5. Название и описание: что нового. Описание лаунчер показывает по кнопке «Инфо».
6. Прикрепите zip. Если версия пробная, отметьте **Set as a pre-release** (в лаунчере будет Beta).
7. **Publish release**. GitHub сам считает SHA-256 файла, лаунчер его проверяет.

Если контрольной суммы у релиза нет, лаунчер напишет об этом в журнале и поставит версию без
проверки. Сумму можно указать в описании строкой `SHA-256: <64 символа>` или приложить файл
`SHA256SUMS.txt`.

## Теги релизов

- Версии Portabilizer: `v8.7`, `v8.8`, `v8.9-beta` (тег начинается с `v` и числа).
- Всё, что не похоже на версию (например `launcher-v0.3` для самого лаунчера), в список
  версий Portabilizer не попадает.

## Запуск и сборка

```
python launcher.py            # запуск из исходников (нужен Python 3.9+ с tkinter)
build_launcher.bat            # сборка Portabilizer Launcher.exe в папку dist
python tests/test_core.py     # проверка ядра (скачивание, суммы, безопасная распаковка)
python tests/test_model.py    # проверка списка версий и окна (на поддельном tkinter)
python tests/test_updates.py  # уведомление о новой версии, фильтр тегов, ярлык
```

## Устройство

| Файл | Что внутри |
|---|---|
| `launcher.py` | окно и модель (список версий, действия) |
| `pz_core.py` | GitHub Releases, скачивание, проверка суммы, установка, запуск |
| `pz_theme.py` | темы оформления и палитры с проверкой читаемости |
| `tests/` | тесты без окна и без интернета |

Настройки лаунчера лежат рядом с ним в `launcher_settings.json`, кэш списка версий в
`releases_cache.json`.

## Безопасность

- Распаковка не выходит за пределы папки версии (защита от `../` в архиве).
- Контрольная сумма проверяется до распаковки.
- Лаунчер только скачивает и запускает `Portabilizer.exe` из ваших релизов. Свой код из
  интернета он не исполняет.


## Два репозитория (рекомендуется)

* `Portabilizer-launcher` (этот): код лаунчера и его релизы с тегами `launcher-v0.3`, `launcher-v0.4` ...
* `Portabilizer`: релизы самой программы (`v8.9`, `v9.0` ...). Откуда лаунчер берёт версии, задаётся константами
  `VERSIONS_OWNER` / `VERSIONS_REPO` в `pz_core.py` или настройкой `versions_repo` (`владелец/репозиторий`) в
  `launcher_settings.json`. По умолчанию это `Vanyok-gh/Portabilizer`.

Лаунчер сам проверяет, вышел ли релиз `launcher-vX.Y` новее установленного, и предлагает открыть страницу загрузки.

## Сборка exe на GitHub

Создайте тег `launcher-v0.3` (Releases -> Draft a new release -> новый тег). Workflow
`.github/workflows/release-launcher.yml` соберёт `Portabilizer Launcher.exe` на Windows и приложит zip к релизу.
Локально: `build_launcher.bat`.

## Переводы

Все тексты окна лежат в `pz_i18n.py`: ключ - русская фраза, значение - английский, эстонский, французский,
испанский. Чтобы добавить язык, допишите его в `LANGS` и в каждую строку `TABLE`; `tests/test_i18n.py`
проверяет, что ни один текст в коде не остался без перевода.

## Иконки

`launcher.ico` (exe), `pz_icons.py` (окно): гладкая для обычных тем, пиксельная при теме «Классическая (системная)».

## Что должно быть в релизе версии Portabilizer

Любой из вариантов: приложенный `Portabilizer.exe`, либо zip с `Portabilizer.exe` внутри (можно в одной вложенной папке).
Лаунчер сам перебирает файлы релиза и берёт тот, где есть программа; исходники он пропускает. Автосборка
(`.github/workflows/release-portabilizer.yml` в репозитории Portabilizer) делает это без ручной работы: создали тег `v8.9`, получили релиз с exe.

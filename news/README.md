# Переводы «Что нового»

Лаунчер показывает описание версии из релиза Portabilizer (оно на русском). Если язык интерфейса не русский,
лаунчер ищет перевод здесь: `news/<код языка>.md`, затем `news/en.md`, иначе остаётся русский текст.

Формат такой же, как у CHANGELOG: раздел каждой версии начинается с `## v9.1`.
Файлы читаются прямо с GitHub (ветка main), поэтому перевод новой версии появляется у всех сразу,
без выпуска нового лаунчера.

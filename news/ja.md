# Portabilizer の新機能

## v9.1

- インターフェイス言語: Windows の設定のような「言語」タブ（地球儀アイコン付き）を追加。各言語は自身の名前で表示され、その下にインターフェイス言語での名前が表示されます。ウィンドウ、ヒント、ログ、ダイアログ、履歴が翻訳されています。言語を変更するとウィンドウが再起動します。設定は保持されます
- 言語: 34 (русский, English, Eesti, Français, Español, Deutsch, Italiano, Português, Nederlands, Polski, Українська, Svenska, Suomi, Türkçe, 中文, 日本語, 한국어, العربية, Čeština, Română, Magyar, Ελληνικά, עברית, हिन्दी, Indonesia, Tiếng Việt, ไทย, Български, Српски, Hrvatski, Latviešu, Lietuvių, Norsk, Dansk)
- 初回起動時は Windows の言語を使用します（翻訳済みの言語に含まれる場合）。含まれない場合は英語になります
- portabilizer.log ファイルは引き続きロシア語で書き込まれます。これによりエラーの原因を調べやすくなります

## v9.0

- ライブラリのインストールは不要: ゲームやアプリに必要なライブラリをプログラムが検出し、exe の隣に配置することを提案します（ファイルは Portabilizer に内蔵されています）
- DirectX: 古いゲーム向けに、2010 年 6 月版および 2005-2009 年の旧リリース（d3dx9_24…43、d3dx10、XACT、XAudio、xinput）
- Visual C++ 2010、2012、2013、2015-2022、OpenAL（wrap_oal.dll を含む）
- プログラム自身で読み取れない Cab セットもスキップされなくなりました。展開は expand.exe（Windows）が行います
- ライブラリセットは tools/collect_redist.bat スクリプトで作成されます

## v8.9

- モード R: 通常の exe はコピーされず、App フォルダーに移動されるようになりました。同じドライブ上では一瞬で終わり、追加の容量も不要です（以前は実行中に倍の容量が必要でした）
- アーカイブとインストーラーでは、モード R は引き続き容量が必要です。先に展開され、その後で元のファイルが削除されます。「保存先」欄を使って別のドライブに展開することもできます
- モード R のヒントと確認ウィンドウを更新しました
- 「クラシック（システム）」テーマでは、ピクセル調の鉛筆アイコン（通常版は青、R は赤）を使用します。他のテーマでは滑らかなアイコンのままです

## v8.8

- 更新の確認: プログラム自身が GitHub Releases を確認し、新しいバージョンが公開されると通知します（「バージョン」タブのチェックボックスでオフにできます）
- Portabilizer Launcher との連携を改善: バージョンの一覧表示、「新機能」の説明、ワンクリックでのインストール

## v8.7

- テーマ: ライト、ダーク、モード R 用の赤いテーマ、好きな色の選択
- インストール済みの 7-Zip を自動検索
- DirectX ライブラリをプログラム内に内蔵（ゲームに不足している場合はダイアログが表示されます）
- 管理者権限を要求するプログラムを、UAC の確認なしで起動
- 重複していたメモリのヒントを削除

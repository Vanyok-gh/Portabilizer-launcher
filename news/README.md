# Переводы «Что нового»

Лаунчер показывает описание версии из релиза Portabilizer (оно на русском). Если язык интерфейса не русский,
лаунчер ищет перевод здесь: `news/<код языка>.md`, затем `news/en.md`, иначе остаётся русский текст.

Формат такой же, как у CHANGELOG: раздел каждой версии начинается с `## v9.1`.
Файлы читаются прямо с GitHub (ветка main), поэтому перевод новой версии появляется у всех сразу,
без выпуска нового лаунчера.

## Если перевода нет

Для новой версии, которой ещё нет в `news/`, лаунчер сам переводит русское описание через бесплатную
точку Google Translate (без ключа, неофициальную). Имена файлов, DirectX, 7-Zip и т.п. он прячет от перевода;
если что-то потерялось или связи нет, показывается английский текст из `news/en.md` или русский из релиза.
Готовый перевод из этой папки всегда главнее машинного. Результат хранится на диске (`news_mt_cache.json`).
